#Event Management App for CS 360

This is an android application that was built to manage events for groups and individuals. It was initially
developed as a course project for CS 360, and demonstrates my use of SQLite for local data persistence. 


##Current Status of the Project
The app is currently **in development**. The core database and UI structure are implemented,and I plan on expanding its core functionality.


## Implemented Features
-SQLite Database Setup using 'SQLiteOpenHelper'

-Creating and Saving new events

-Viewing a list of saved events

-Basic UI with the date/time pickers


##Features Planned:

-Edit and Delete already existing events.

-Allowing a calendar view for event browsing.

-Push Notifications for upcoming events.

-Deploying to the Google Playstore.

##Technologies Used:

**Language:** Java

**Database:** SQLite

**Tools:** Android Studio,Gradle

##How To Build

1.)Clone the repository.

2.)Open Project in Android Studio.

3.)Run app on emulator or the physical device.

## Future Goals
This project is part of my ongoing learning in Android development. I plan to continue building it out and eventually deploy it to the Play Store as a fully functional app.
